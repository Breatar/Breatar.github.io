# 电子邀请函 · 鎏金瓷白

中式电子请柬，**一个 HTML 文件**，图片已全部内联，不再依赖文件夹 —— 可以直接转发。

- 先填信息 → 一键生成 → 姓名 / 日期 / 时间 / 地点 / 电话自动覆盖到请柬里
- 手机全屏打开，像小程序一样使用（底部工具条 + 底部面板，无跳转无刷新）
- 一键生成**分享长图**（微信里长按即可保存转发）或**独立网页文件**
- 支持"添加到主屏幕"，桌面图标打开即为全屏 App 观感

## 一、三种转发方式（按省事程度排序）

| 方式 | 怎么做 | 适合场景 |
| --- | --- | --- |
| **① 发图片（最省事）** | 打开请柬 → 底部「分享转发」→ **保存图片** → 长按保存到相册 → 微信里发图 | 微信群、朋友圈，人人可看，零门槛 |
| **② 发网页文件** | 同一面板点 **保存网页** → 得到一个 `邀请函-张三.html`（约 200–400 KB）→ 当作文件发给对方 | 对方要"点开还能翻页看完整请柬" |
| **③ 发链接（最像小程序）** | 把 `index.html` 传到任意静态托管 → 复制链接发出去 | 正式群发、二维码、公众号 |

> 方式③ 只需要把 `index.html` 这一个文件上传（不用传文件夹），推荐 GitHub Pages、Vercel、腾讯云 COS、阿里云 OSS 等静态托管，**不需要服务器和后端**。上传后拿到的网址，微信里点开就是完整请柬。

![分享转发](preview/02-分享转发.jpg)

## 二、怎么用

1. 手机浏览器打开 `index.html`（或托管后的链接）；
2. 首次打开自动弹出「填写信息」面板；
3. 填好后点 **生成邀请函** —— 封面、称谓、日期、农历、时间、地点、桌号、流程时间、回执截止日、倒计时全部自动更新；
4. 回到封面，轻点「轻触开启」进入请柬；
5. 之后随时点底部 **✎** 修改，改完再点生成即可，数据不会丢。

底部工具条：**编辑信息 / 背景音乐 / 分享转发 / 保存 PDF**。

![填写表单](preview/05-填写表单.jpg)

## 三、换成自己的照片

### 方式 A：在页面里上传（不需要任何工具，推荐）

点 **✎** → 滑到「图片」→ 点四个格子分别上传（主视觉 + 3 张影集图），会自动压缩后存进页面。
然后点 **分享转发 → 保存网页**，导出的那个 `.html` 就已经包含你的照片，直接发给别人即可。

### 方式 B：替换源图后重新打包（要做成正式版、托管链接时用）

1. 把照片放进 `assets/img/`（建议尺寸见下表，文件名保持一致，或同步改 `src/page.html` 里的引用）；
2. 运行一次打包脚本，`index.html` 会被重新生成（图片全部内联）：

```bash
python tools/build_single.py
```

| 文件 | 用途 | 建议尺寸 / 比例 |
| --- | --- | --- |
| `assets/img/hero.svg` | 主视觉大图 | 竖图 3:4 或 4:5，≥1200×1600 |
| `assets/img/photo-1.svg` | 影集大图 | 16:10，≥1200×750 |
| `assets/img/photo-2.svg` | 影集方图 | 1:1，≥900×900 |
| `assets/img/photo-3.svg` | 影集方图 | 1:1，≥900×900 |
| `assets/img/map.svg` | 位置示意图 | 16:9，≥900×520 |

照片可以直接用 `.jpg` / `.png`，把文件放进 `assets/img/` 并在 `src/page.html` 里把引用改成对应文件名即可，打包脚本会按扩展名自动识别。

## 四、字段与请柬位置的对应关系

| 表单字段 | 请柬里出现的位置 |
| --- | --- |
| 宴会类型 | 封面印章字（囍/寿/喜/贺/谢）、封面大字水印、主视觉类型、默认标题与寄语 |
| 请柬标题 | 主视觉大标题（留空用该类型默认标题） |
| 主宾姓名 | 主视觉姓名行（两位用空格分隔，自动排成「甲 · 乙」） |
| 邀请人 / 落款 | 封面「XX 敬邀」、正文落款、页脚 |
| 受邀人姓名 / 称谓 | 封面「致 XX 先生 台启」、正文「尊敬的 XX 先生：」 |
| 宴会日期 | 主视觉日期、日期卡、**农历**、正文「谨定于…」、回执截止日（提前 7 天）、倒计时 |
| 开席 / 恭候时间 | 时间卡、正文、**宴会流程每一步时间**、倒计时 |
| 酒店 / 宴会厅 / 桌号 / 地址 | 地点卡、正文、高德地图一键导航 |
| 邀请寄语 | 正文第一段（留空用该类型默认寄语） |
| 回执联系人 / 电话 | 回执区「致电 XX」一键拨号 + 复制 |
| 配色主题 | 朱砂 / 青瓷 / 夜宴，整页 + 分享长图联动 |
| 图片 | 主视觉 + 影集三张 |

## 五、改文案 / 配色 / 默认信息

- 默认示例：`src/page.html` 里 `function makeDefault()`
- 宴会类型、默认标题、默认寄语、印章字：`var TYPES = {...}`（婚宴 / 寿宴 / 满月 / 升学 / 乔迁 / 答谢，可增删）
- 称谓选项：`var SALUTATIONS = [...]`
- 配色：CSS 顶部 `:root`、`html[data-theme="jade"]`、`html[data-theme="night"]`
- 宴会流程：`render()` 里的 `var flow = [...]`

改完记得重新打包：`python tools/build_single.py`


## 七、说明与注意

- **数据只存在本机**（浏览器 localStorage），不会上传任何服务器；导出的网页文件会把数据固化进文件本身。
- **背景音乐**是实时合成的古琴音（不需要音频文件）。浏览器要求先有点击，所以点「轻触开启」后才响；工具条可随时关闭，偏好会记住。
- **农历**由内置对照表计算，支持 1900–2099，已逐日校验。
- **PDF**：工具条「保存 PDF」调起浏览器打印，选「另存为 PDF」，A4 竖版已排版好，自动隐藏封面与工具条。
- **兼容性**：iOS Safari 15+ / Android Chrome / 微信内置浏览器 / Edge。
- 若上传多张大图后提示「图片较大，未能保存到本机」，说明浏览器本地存储满了，改用「方式 B」打包即可。
